2The Grain 5 mark

  1. Spelling: always Grain 5. Capital G, one space, digit 5. Never "grain5" in text. The CSS ids stay grain5-gold and grain5-unit.
  2. Five gold grains, one tail straight up. Gradient stops #F9E27D → #D4A017 → #B8860B → #E6C34A, top-left to bottom-right.
  3. Placement: in the page header only, left of the h1, vertically centred on the title block. Not repeated inside cards.
  4. Size matches the title block height: 84 px when h1 is 60 px with a stamp line under it (Macro Desk, Premarket News); 64 px for Ticker Desk; 56 px on the wide Trader page.
  5. Always inline SVG with the sprite from the grain5 artifact, aria-label="Grain 5 mark". Never a raster image.
  6. Trade Map and Daily Price do not carry the mark yet. Adding it is allowed and follows 2.3 and 2.4.

4Typography

  1. Three faces, one Google Fonts link: Instrument+Serif, IBM+Plex+Sans:wght@400;500;600, IBM+Plex+Mono:wght@400;500;600. No other family.
  2. Serif = titles only: h1 60 px (line-height 0.95), h2 26–34 px, ticker names 36 px, pillar titles. Weight 400, never bold.
  3. Mono = every label, stamp, chip, date, time and number. Uppercase labels get letter-spacing 0.10–0.14 em. Numbers get tabular-nums.
  4. Sans = values and prose. Card values 16–18 px in --meta; a bold inside a value is --ink 600.
  5. Base size: 21 px on reading pages (Ticker Desk, Macro Desk, Premarket News), 18 px on dense pages (Trade Map, Trader).
  6. Label sizes: stamp line 14–15 px, kv keys 12–13 px, chips 11–12 px, table headers 11 px.

5Page layout

  1. Phone first. One column, .wrap max-width 480 px centred, padding 28px 22px 40px, flex column, gap 26 px. Trader is 720 px because of its table.
  2. Header: logo + h1 + stamp line, then a 3 px solid --ink rule with 18 px padding below. This rule is the page's signature; never thinner, never a color.
  3. Stamp line under the title, mono uppercase muted: market macro update · 25 Sep 2026 · midday, 11:20 ET. Parts joined by " · ".
  4. Border radius 0 everywhere. Cards, chips, buttons and tables are square. Only exceptions: pill FABs (999 px) and the 9 px status dot.
  5. No shadows on cards. Only the fixed FABs carry a shadow.
  6. Cards: --surface, 1 px --line border, 20 px padding, 14 px inner gap. Nested rows use --surface-2.
  7. Safe areas respected: fixed bottom bars add env(safe-area-inset-bottom).
  8. Nothing scrolls sideways except a table inside its own overflow-x:auto wrapper (Trader adds a sticky scroll proxy bar).
  9. No thick accent rail on the left (or any side) of a box. Notes, callouts and cards use the plain 1 px --line border only. Set by Moran, 26 Sep 2026.

6Components

6.1 Status chips and flags

knownpendingwaitingpollingtimed updownmixflat buysellhold
  1. Chip: mono 11–12 px uppercase, 1 px border in currentColor, padding 3px 8px, no fill, no radius. Color is the state (section 3).
  2. Event status set: KNOWN · PENDING · WAITING · POLLING · TIMED (Trade Map). Trade Map Spec names them PENDING / CONFIRMED / DONE / CANCELLED; map one to one when writing text.
  3. Flag words: UP = two or more space names +3% or more while S&P is not; DOWN = same at −3%; FLAT otherwise. Story flags: positive / negative / mix.

6.2 Folding rows (details)

  1. A list item is a <details>: summary shows date or time (mono 18 px 600 accent) + title (17–18 px) + a 30 px square "+" toggle. "−" when open.
  2. Rows are separated by 1 px --line, padding 16px 20px. The card holding them has padding 0 and a padded label on top.
  3. Highlighted rows (.hi) show the date in --warn.

6.3 Key-value rows

  1. Grid fit-content(35%) minmax(0,1fr), gap 4px 12px. Label column at most 35% of the card, value column at least 65%. Labels may wrap to 2 lines; values never more than 4.
  2. Keys mono 12–13 px uppercase muted. Values sans 16–18 px meta.
  3. Fixed key sets: Trade Map today card = Outcome / Expect / one row per scenario / History / Fired. Event watch = Window / Last check / Checks / Outcome / Source / Fired. Roadmap and stories = Cause / Effect / Expect (Ticker Desk adds Exceptions; Trade Map adds Do).

6.5 Roadmap rows

  1. Numbered rows: bold mono date (30 Sep · after close) + one-line description + mono 13–14 px meta line Regulatory · confirmed · impact med + impact chip + "+" that opens the note.
  2. Same look on Ticker Desk, Macro Desk and Premarket News. Ticker Desk is the source (section 9).

6.6 Tables (Trader, Daily Price)

  1. Outer border 2 px --meta, cell borders 1 px --line, header row --surface-2 with 2 px bottom rule. Cells mono 14 px tabular, right-aligned, first column left, date centred, height 40 px.
  2. Side chips inside cells: buy good, sell accent, hold warn, flat muted. New rows tinted rgba(95,179,255,.10).

6.7 Buttons

  1. Outlined only: mono 11–14 px uppercase, 1 px --accent border, accent text, min-height 36 px, no fill. Hover inverts.
  2. Fixed pill FABs (Back / Log) sit bottom left and right, --surface fill, 1 px accent border.

6.8 Position line

  1. Last line of a Trade Map card, mono 12–13 px muted: $58.00 = 10 sh (unchanged); 6 sh held, 25-share max.

6.9 Trump tape

  1. Tapping "Trump tape" opens three cards, in this order: Highlights · Roadmap of events (White House schedule, meetings, announcements; timeline format per 6.5) · Truth Social announcements.
  2. Every item on these cards (highlight, event, post) is stacked topic → date + time stamp → information. The stamp sits on top of the information, never at the end. Time per 7.7: 25 Sep 2026 · 23:26 ET (06:26 Israel).
  3. The information block uses the Cause / Effect / Expect key-value rows (6.3, 8.4), same as every other story card.
  4. Each of the three cards carries its own "last updated" stamp in the card label (mono, muted, 8.6 format).
  5. Every item is a folding row (6.2), closed by default. Closed it shows only topic, stamp and flag with the "+" toggle; "+" opens the information (Cause / Effect / Expect, or the post text and source link). Set by Moran, 26 Sep 2026.

6.10 Card groups: tab row and sub-filter row

Display option for a page that holds more than one group of cards (first used on Trump Desk, 26 Sep 2026). One tap moves between groups; a second, smaller row narrows the group in view. Sample below.

3 · Truth Social · last updated 26 Sep 2026 · 13:06 ET (20:06 Israel) · sample
  1. Tab row (group switch): sits directly under the header rule, above the cards. Equal-width grid, one column per group, gap 8 px. Each tab: mono 11 px uppercase, letter-spacing .08 em, 1 px --accent border, no fill, min-height 40 px, square. Label = group number + name (1 Highlights); the number is the one the user says in chat.
  2. Selected tab: filled --accent, text --ground. One tab is always selected; the page opens on tab 1 unless the URL hash names another (#roadmap, #truth). The last tab used is remembered per device.
  3. Only the selected group's card is visible; the others are hidden, not collapsed. Each group is one card with its own label and "last updated" stamp (6.9.4).
  4. Sub-filter row (narrows the group in view): first row inside the card, under the label, padding 12px 20px, 1 px --line under it. Buttons: mono 11 px uppercase, 1 px --accent border, min-height 32 px, no fill; pressed = filled accent (aria-pressed). First button is always "All".
  5. Use 2 to 4 tabs and 2 to 4 sub-filters. More than that: split the page or use the folding rows of 6.2 inside one card.
  6. Both rows use <button> with role="tab" / aria-pressed, visible focus ring in --warn. Tapping a tab must not scroll the page.
  7. Pages that may adopt it: Ticker Desk (one tab per ticker), Macro Desk (Numbers · Pillars · Roadmap), Premarket News (Overnight · Pre-market · Trump). Adoption is a per-page decision; note it in section 11 until done.

6.11 Side numbers on lists

  1. Side numbers only where the user refers to rows by number: roadmap rows (6.5), triggers, and the tab labels of 6.10.
  2. Dated lists carry no side numbers. The bold date at the start of the row is the key: past 7 days, beyond the window, log entries, Truth Social posts. Set by Moran, 26 Sep 2026.
  3. Dated row format: bold mono date first (22 Sep close), then the text runs on inline after it, filling the row edge to edge, no second column, no indent. Approved by Moran, 26 Sep 2026.

8Content rules

  1. Each card value is at most 25 words. Numbers and the action; cut the prose.
  2. No number is repeated across rows of one card. Past moves go once, in the HISTORY row.
  3. EXPECT holds the moves only (UP 3–6% clean flight · DOWN 5–7% slip). Scenario rows hold the action only (Buy ≤ $58.00 = 10 sh).
  4. Driver template for every story, pillar and roadmap note: Cause / Effect / Expect, each ≤ 25 words, plain words, no jargon. Ticker Desk adds Exceptions.
  5. Read line: one sentence that says what the numbers mean, right under the numbers.
  6. Every page shows its own stamp: date, session (open+30 / midday / close / overnight) and the time it was rendered, in ET.
  7. Change notes live in the page as comments with date and "Moran" when the user asked for them, and in this guidebook's change log.
  8. Sample data is labelled as such. Never show example numbers as live.
  9. Every announcement, event or highlight shown on any page carries its own date + time stamp (7.5, 7.7), placed on top of the item: topic → date/time → information. No undated items.
  10. Information is folded by default: a list item shows its title (topic, stamp, flag) and a "+" button; the full text opens on tap (6.2, 6.9.5). Long text is never shown open in a list.

9Ownership & data flow

  1. Ticker Desk owns the roadmap. Trade Map analyses it and Premarket News shows it; neither edits it.
  2. Trade Map owns the plan (buy line, stop, trim, size). Other pages quote its numbers, never recompute them.
  3. Trader owns the ledger and the last-run verdict; profit on sells uses oldest lots first.
  4. Daily Price reads the Google Sheet as is; day change, price, YTD and since-dip are the sheet's own columns.
  5. Routines rewrite the data blocks; the renderer below each block is what this guidebook governs. Do not hand-edit data blocks.
  6. Run clock (ET): Trump Desk 00:45 daily, 09:40, 16:03, Sun 17:59 · Ticker Desk 10:00 and 16:15 · Trade Map re-score 10:30 and 16:30 · Trader 10:45, 15:50, 16:45 · scheduler 05:20 and 17:20. Trump Desk always runs before its readers.
  7. Trump Desk owns all Trump information (highlights, roadmap of events, Truth Social posts). Premarket News, Macro Desk and every other page read from it and never duplicate or re-summarise it. If the Trump Desk run fails, readers show its last "last updated" stamp, not stale text presented as fresh.

10Trade Map structure & example

Carried over from the Trade Map Spec (25 Sep 2026). Governs the renderer of the Trade Map; the MAP data block above it is rewritten by routines.

  1. Screen title: "Trade Map". Sub-title h2 "ASTS Playbook" with stamp ASTS · 25 Sep 2026 · close · re-scored 16:41 ET.
  2. Events grouped under a date header, mono uppercase: TODAY · MON 28 SEP 2026 / IN 3 DAYS · MON 28 SEP 2026 / TUE 29 SEP 2026. Date label follows rule 7.3.
  3. One card per event, in this order: time + zone bold (08:15 ET) then a one-sentence headline; status chip; key-value rows; position line.
  4. Status chip set: PENDING / CONFIRMED / DONE / CANCELLED (Trade Map Spec names). Renderer classes: pending = warn, known / confirmed = good, waiting = muted, polling = accent, timed = bad.
  5. Row order: OUTCOME · EXPECT · one row per scenario (move + action) · HISTORY. OUTCOME shows the result, or Pending · polling 08:10–09:45 ET, every 2 min.
  6. EXPECT: one line per direction, e.g. UP 3–6% clean flight · DOWN 5–7% slip/failure. Scenario rows (FLEW CLEAN / SLIPPED / FAILED): the action only, e.g. Buy ≤ $58.00 = 10 sh.
  7. Position line closes the card: $58.00 = 10 sh (unchanged); 6 sh held, 25-share max.
  8. Layout: label column ≤ 35%, value column ≥ 65% (6.3.1); values ≤ 25 words (8.1); no number repeated, History once (8.2, 8.3).
  9. Safety rules shown on the map: Stop · Trail 15% (17 Sep) · Event exit · Trim +8% at 15:50 ET (18 Sep) · Max size 50% of cash / 25 sh (23 Sep).
  10. Event day cycle, 7 steps: Tag → Plan → Schedule → Poll → Update → Fire → Pass (24–25 Sep).
  11. Process: after every approved change to the Trade Map, update this guidebook in the same session, commit, push. This page is the single source of truth; the old TRADE_MAP_SPEC.md file is retired.

13How to add a rule

  1. User approves a change in chat ("save this as a rule").
  2. Add it to the right section here, with the next number. Never renumber old rules; retire them with "(retired DATE)" instead.
  3. Add a line to the change log (section 14) with the date and the rule number.
  4. Apply it to the page it came from in the same session. If other pages break the new rule, list them in section 11.
  5. Republish this guidebook. Commit the spec note in the repo.
